# AGENTS.md

## Communication

- Default to Chinese for all user-facing output in this repository, including progress updates, analysis, change summaries, and test results.
- Switch to English only if the user explicitly asks for English output.
- Keep code, API names, commit messages, protocol fields, and other repository-native identifiers in their existing language and style unless the user asks to change them.
- When quoting raw errors or upstream tool output, keep the original text and explain it in Chinese when useful.
